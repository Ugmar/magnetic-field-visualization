# magnetic-field-visualization
# 🧲 Magnetic Field Visualization (Визуализация магнитных полей)

[cite_start]Программный комплекс с графическим интерфейсом для интерактивного моделирования, расчета и визуализации распределения индукции и напряженности магнитных полей, создаваемых различными конфигурациями проводников с током[cite: 1, 13, 132]. [cite_start]Проект разработан для проведения лабораторных и исследовательских работ по физике и электродинамике[cite: 12, 13].

---

## 🛠 Технологический стек

[cite_start]В основе проекта лежит разделение на вычислительное ядро (Core), графическую оболочку (GUI) и автоматизированный контур контроля качества кода[cite: 1].

### Основные технологии и библиотеки:
* [cite_start]**Язык программирования:** `Python 3.12+` — современный стандарт для научных расчетов и быстрой разработки приложений.
* [cite_start]**Вычислительное ядро физики:** `magpylib >= 5.2.0` — продвинутая библиотека для расчета магнитных полей в свободном пространстве[cite: 41, 55, 59]. [cite_start]Обеспечивает точный расчет векторов индукции $\vec{B}$ для сложных систем источников (через аналитические 3D-модели `Polyline`, `Circle` и др.)[cite: 16, 42, 56, 59].
* [cite_start]**Математический аппарат:** `NumPy` — векторизованные вычисления, генерация сеток координат (meshgrid) и проведение линейно-алгебраических операций над массивами данных с высокой производительностью[cite: 41, 42].
* [cite_start]**Графический интерфейс (GUI):** `PyQt6 >= 6.9.1` — кроссплатформенный фреймворк для построения отзывчивого UI[cite: 31, 132]. [cite_start]Реализует событийно-ориентированную архитектуру, кастомную интерактивную интерактивную область рисования (`Canvas`) [cite: 41][cite_start], динамические формы объектов и вывод метаданных поля под курсором в реальном времени[cite: 20].

### Инструменты обеспечения качества (Code Quality & DevTools):
* [cite_start]**Форматирование:** `black` и `isort` — для автоматического приведения кода к единому стандарту PEP 8 и упорядочивания импортов[cite: 9, 31].
* [cite_start]**Линтинг:** `flake8` — статический анализ кода на наличие ошибок и стилистических отклонений[cite: 1, 9].
* [cite_start]**Автоматизация пайплайнов:** Автоматические Git-хуки (`hooks/pre-commit`) для проверки и автоформатирования измененного кода прямо перед коммитом[cite: 9, 31].
* [cite_start]**Сборка:** `pyinstaller` — компиляция исходного кода в независимый исполняемый `.exe` файл (Standalone Production Build) для Windows и Unix систем[cite: 1, 10, 11].

## 🔥 Ключевые возможности

1.  [cite_start]**Разнообразие источников тока:** Поддержка создания прямых бесконечных проводов [cite: 13, 53][cite_start], точечных проводников (перпендикулярных плоскости экрана) [cite: 30, 60][cite_start], кольцевых токов [cite: 57] [cite_start]и произвольных замкнутых контуров[cite: 61, 62].
2.  **Продвинутая визуализация:**
    * [cite_start]Градиентная тепловая карта (Heatmap) интенсивности поля с логарифмическим сглаживанием выбросов через перцентили ($P_5$ и $P_{95}$)[cite: 42, 43, 164].
    * [cite_start]Векторная сетка направлений силовых линий (динамические стрелки и обозначения «к нам» $\bullet$ / «от нас» $\times$)[cite: 18, 48, 49].
    * [cite_start]Интерактивная шкала (легенда) магнитной индукции в Теслах[cite: 45, 46].
3.  [cite_start]**Экспериментальный модуль:** Возможность интерактивной проверки закона Био-Савара-Лапласа, принципа суперпозиции и поиска равновесных точек компенсации полей[cite: 13, 16, 27].

## 📁 Архитектура проекта

```text
magnetic-field-visualization/
├── core/                       # Вычислительное ядро приложения
│   ├── FieldManager.py         # Расчет сеток поля, генерация тепловых карт и векторов
│   ├── ObjectManager.py        # Конвертер внутренних объектов в структуры magpylib
│   └── objects.py              # Описание физических объектов (Wire, Ring, PointWire)
├── gui/                        # Графическая оболочка приложения (PyQt6)
│   ├── main_window.py          # Главное окно и разметка интерфейса
│   ├── controller.py           # Логика взаимодействия UI и физического ядра
│   └── widgets/                # Кастомные виджеты (холст холста, панели управления)
├── hooks/                      # Контур Git-автоматизации (Pre-commit автоматика)
├── lab_report.tex              # Шаблон отчета по лабораторной работе (LaTeX)
├── main.py                     # Главная точка входа в приложение
├── Makefile / build.bat        # Скрипты автоматизации сборки под Unix / Windows
└── requirements.txt            # Зависимости проекта


# Unix

Build binary executable
```sh
make build
```

Run from sources without building binaries
```sh
make run
```

# Windows
Build binary executable
```sh
./build.bat
```

Unfortunately develop environment setup for Windows is not available due to makefile is not crossplatform
